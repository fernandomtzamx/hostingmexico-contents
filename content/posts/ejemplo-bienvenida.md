# Bienvenido

Este post fue creado por **Claude** a través del repositorio de GitHub y sincronizado por el mu-plugin `agente-auth` con el usuario *soporte*.

## Cómo funciona

1. Claude escribe o edita un archivo en `content/posts/` o `content/pages/`.
2. GitHub avisa al sitio mediante un webhook.
3. El plugin descarga el archivo y crea o actualiza el post.

> Si este post aparece como borrador en tu sitio, la conexión ya funciona.
